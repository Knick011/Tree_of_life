Download the prescriber extension for free

TOL Scribe EMR Filler opens on supported browser-based EMR prescription pages and fills fields from a clinician-copied TOL Scribe prescription draft.

For Chrome, Edge, Brave, and other Chromium-based browsers Final review and signing stay inside the EMR

Opening the extension store

You will be redirected to the Chrome Web Store. If the redirect does not open, use the button below.

Open store

How it works

  • Build a prescription draft in TOL Scribe.
  • Use Copy for EMR.
  • Open the supported EMR prescription page.
  • Click TOL Fill, then review the filled draft before saving or signing.
TOL Scribe pilot release. Not for clinical use.
